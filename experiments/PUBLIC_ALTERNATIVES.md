# Public datasets close to the project statement

The project uses public alternatives because official SemEval-2025 Task 10 data
cannot be obtained. The central architecture remains a frozen cross-lingual
transformer plus a trainable hierarchical label GCN. Native persuasion techniques,
climate claims, sentiments and narrative labels are not interchangeable.

## Main public experiments

**Cleaned CARDS/4C** supplies climate-claim labels and their native hierarchy.
It supports a narrative-related English classification experiment; its single-label
paragraphs do not reproduce the full multilingual, multi-label SemEval task.
The existing results and original protocol remain unchanged.

**[ProBel](https://huggingface.co/datasets/QCRI/ProBel)** adds English/Arabic news
units with native multi-label persuasion techniques, 23 fine labels grouped into
six coarse categories, character evidence spans and explanations. It is released
under CC BY-NC-SA 4.0; underlying source texts retain their original terms.
We use its news records only. Arabic social-media posts are excluded.
The explanations were generated by OpenAI o1 and evaluated by the publisher's
human reviewers. They are model-authored references, not human-written gold.
Their human ratings do not evaluate our generated outputs.

The release is pinned to revision
`076ac4ebcf5c1d87e6679d3e21205159f00ae7db`. The preparer checks SHA256 for
all six data files, the label taxonomy, license and README. Raw text, source IDs,
reference explanations, spans, predictions and weights remain local and ignored.

```powershell
python -m experiments.public_probel
python -m experiments.run data/public/probel/experiment.json --resume
```

The first command prepares the fixed pilot; the second runs the three baseline
methods and three GCN variants. Native multi-label decoding permits an empty set
for a record with no annotated technique. There is no invented Other category.
Development macro F1 chooses the classifier setting and threshold. All 23 native
techniques remain in the macro-F1 inventory, even when rare or absent in a subset.
GCN seeds are 13/42/87; its label initialization uses names, not guideline
paraphrases. The random-vector ablation therefore removes label-name semantics.

## Source-article leakage and custom split

The downloaded release has source page IDs shared across its sentence-level
partitions. We pooled the news rows, connected source articles through exact
normalized duplicate content, and split article groups 70/15/15 using seed 42.
Conflicting duplicate labels were excluded; duplicates were collapsed only after
group assignment. Every retained record's evidence spans were checked against
its original text. No source annotation was silently repaired.

Before fitting any model, we capped each language at 800 training and 200
development/test records, preserving that language/partition's native binary
label proportions. Totals: 1,600 train, 400 development and 400 test, with 200
held-out examples per language. This is a researcher-defined pilot, not the
publisher's benchmark split or a score comparable to its paper. Exact duplicates
and known source-article overlap are audited; translations and near duplicates
beyond exact matching are not established. See [the released aggregate audit](../results/probel-protocol.json)
for preparation counts and checksums; source IDs and text remain ignored. Training features use text only; references,
spans and gold technique labels are not concatenated into the classifier input.

## Cross-lingual transfer

```powershell
python -m experiments.probel_transfer
```

Train frozen MiniLM + logistic regression and MiniLM + full GCN on only English
training data, selecting settings using only English development data. Evaluate
both English and Arabic held-out records. Repeat with Arabic as the source.
No target-language development labels enter selection. These transfer pilots use
one seed (42) and the same native label inventory. They assess frozen-encoder
transfer, not fine-tuned XLM-R or Task 10 performance. Language/source/class
imbalance differences must accompany any transfer gap. Run after the main
classification comparison to reuse its embedding cache.

## Local explanation comparison

Start the loopback-only Qwen3 server documented in PUBLIC_DATA.md, then run:

```powershell
python -m experiments.probel_explanations --gguf work/models/Qwen3-1.7B-Q4_K_M.gguf
```

The preparer fixes 40 held-out examples: ten per language and native binary-label
stratum, seed 42. Given the native techniques, compare TextRank, semantic
extraction, semantic-context Qwen generation and leading-context generation.
References and source spans are withheld from prompts. The short news units
may give identical evidence to the two generator variants; the runner reports
that rate and visibly reuses outputs for exactly equivalent prompts. Only sentence
IDs and text reach the generator; ranking scores remain internal. This does not
become a retrieval-quality test merely because both
selection methods are implemented.

BERTScore uses cached multilingual BERT layer 9, no IDF or baseline rescaling,
and is reported per language. It measures similarity to publisher model-authored
references, not factuality, human grounding judgments or dominant narrative
explanation quality. Gold technique labels are supplied. Our outputs require
human review for grounding and language quality. All model revisions and local
generator settings follow PUBLIC_DATA.md.

## Supporting experiments and unavailable candidates

YASO targeted sentiment and e-SNLI inference explanations remain supporting
component experiments. Neither is the central multilingual propaganda evaluation,
and YASO does not supply protagonist/antagonist/innocent role labels.

[PolyNarrative](https://nikon95.github.io/narrative-detection/) and
[NarratEX](https://github.com/LIAAD/NarratEX) require registration and vetted access
through the same SemEval Task 10 service. Their public papers are not an ungated
alternative release. INDI-PROP also requires an access-request form. They have
not been downloaded or represented as available datasets.

The exact Task 10 entity-framing task and dominant-narrative explanation quality
remain unevaluated. Public alternatives support related research, while keeping
that limitation explicit.
