# Project website

Buildless HTML/CSS/JavaScript. Serve `dist/` with any static web host:

```powershell
python -m http.server 8000 --directory website/dist
```

Open http://localhost:8000. Features include a responsive project explanation,
interactive label-family diagram, expandable ablations, and component/dataset
filters for reviewed aggregate results. Fonts use local system fallbacks; no
external stylesheet is required. The illustrative article is invented and marked.

`dist/results.json` is generated by `python -m experiments.publish` from reviewed
real experiment summaries. Each record retains `dataset`, `label_schema`, task,
metric, count, commit, source/data hashes, scoring provenance, and seed variation, and available per-language scores. The board opens on the grouped
ProBel news pilot; choose another dataset to inspect earlier component results.
Native CARDS, bilingual ProBel, YASO, and e-SNLI results remain separate from the empty official
SemEval view. Never populate the board with synthetic checks or other teams' scores.

The exporter also writes `results/measurements.json`, diagnostic aggregates, and
per-dataset SVG plots. After new measurements, review the findings prose in
`dist/index.html` alongside the data; it is an editorial account of a fixed run.
Compare scores only within their dataset and metric. No raw source text, reference
explanations, model weights, or live model endpoint is hosted.

Hosting identity lives in `.openai/hosting.json`. Preserve the existing private
Site's identity and access settings when publishing an update.
